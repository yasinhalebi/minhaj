# منهاج

فهرس تعليمي عربي مستقل لمحتوى الشيخ أحمد السيد. التسجيلات تبقى على YouTube؛ الموقع ينظم الوصول إليها ولا يستضيفها.

## التشغيل المحلي

```powershell
npm install
npm run dev
```

افتح `http://localhost:3000` لمعاينة الصفحة الرئيسية.

## الحالة

المشروع في المرحلة 1: هيكل أولي للواجهة. المحتوى الذي يظهر في المعاينة تجريبي بوضوح، وليس مواد منشورة أو معلومات موثقة.
